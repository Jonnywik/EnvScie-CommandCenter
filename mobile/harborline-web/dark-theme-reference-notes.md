# Referenced Dark-Theme Direction

The referenced Code for Resilience interface uses a **near-black blue-green command surface**, a compact brand lockup, white primary type, and muted aqua uppercase operational metadata. Its visual hierarchy is restrained: information is separated primarily through spacing, weight, and subtle tonal shifts rather than bright borders or many accent colors.

Transferable traits for Harborline are a unified charcoal-navy base, low-glare raised surfaces, cool aqua secondary text, a focused teal action accent, compact uppercase utility labels, and a calmer operational header. Emergency severity colors remain semantic and distinct to protect accessibility and crisis recognition.
