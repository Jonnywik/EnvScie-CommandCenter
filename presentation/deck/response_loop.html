02 · System response

One system connects warning, movement, and assistance.

Code for Resilience connects the resident’s decision path to an operational view for the LGU—without treating online connectivity as a permanent condition.

Residents

Receive verified alerts, view risk layers, locate centers, and request help.

Resilient transport

Use internet normally, then compact SMS when connectivity is degraded.

Municipal operations

Triage SOS incidents, dispatch resources, and monitor center capacity.

Re-verify

Keep cached records useful while making freshness explicit to every user.

Decision principle: cached information remains useful, but it is never mistaken for a live verified update.
